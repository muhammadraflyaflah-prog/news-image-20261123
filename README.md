# Sum up 23 November's world news in one image

Entry for make.fun bounty "Sum up 23 November's world news in one image" by @muhammad-rafly-2.

One image, 1024x1024 PNG, summarising 23 November 2026:
1. COP31 climate talks collapse with no deal
2. Democrats win historic 258-seat House majority
3. World Court rules Myanmar committed genocide against the Rohingya
4. Russian strike in Kyiv region kills 11, boy pulled alive from rubble
5. Alcaraz wins ATP Finals and Liverpool beat Manchester United 4-0

Run with Node.js 22 or later:

```
node main.ts
```

It deterministically writes the image to `output/entry.png`.
